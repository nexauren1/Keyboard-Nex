# Keyboard Nex theme assets

This folder is reserved for complete Keyboard Nex theme compositions.

Theme backgrounds should be integrated into a new keyboard design (background image, key surfaces, contrast overlay, labels and controls). Do not redistribute unmodified stock photos as standalone files. Keep a record of the source URL, contributor, license and download date for every third-party asset.

Pixabay assets may be used under the applicable Pixabay Content License, but the license prohibits standalone redistribution. API image URLs must not be permanently hotlinked; the Pixabay API documentation requires downloaded assets to be hosted by the application owner and limits automated downloading. Review the current license before each release.
